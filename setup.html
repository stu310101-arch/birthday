寄信啟用與測試

這頁是給網站擁有者使用的測試頁，主頁沒有通往這裡的按鈕；本頁仍是公開網址。主網頁按「送出」會直接透過 FormSubmit 提交回覆，不開啟任何郵件程式。

正式網址：https://stu310101-arch.github.io/birthday/

固定收件信箱：stu310101@shsh.tw

  1. 先到 GitHub 儲存庫的 Settings → Pages，選擇 Deploy from a branch → main → / (root) 並儲存。網站發布後，用本頁的正式 HTTPS 網址開啟。
  2. 點下方按鈕，實際送出一封標示為「啟用／驗收測試」的信。首次使用時，請收件人到上述信箱找到 FormSubmit 啟用信，按 Activate Form。也請查看垃圾郵件。
  3. 啟用後，再按一次按鈕。確認收件信箱收到本頁顯示的測試編號，即完成實際驗收。服務回覆成功不等同於已在收件匣確認到信。

換了網站網址時，請在新網址重新驗收。不要把這個設定頁分享給壽星；分享 index.html 的正式網站網址即可。
